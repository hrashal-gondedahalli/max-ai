# MAX AI\n\nMAX is a browser-based chat interface. The GitHub Pages site hosts the frontend; it cannot securely hold an AI provider secret or run the private AI backend.\n\n## Frontend features\n- Chat interface and suggested prompts\n- Browser speech recognition where supported (microphone permission required)\n- Read answers aloud, repeat, and stop speech\n- Chat history saved in this browser\n- Responsive desktop and mobile layout\n\n## Important current status\nThe frontend starts in demo mode. Real AI replies are not active until the separate Worker backend is deployed and connected. Do not paste an AI API key into index.html, GitHub Pages files, or a public repository.\n\n## Backend template\nworker.js is a Cloudflare Workers-compatible proxy for an OpenAI-compatible chat-completions endpoint. It expects these Worker environment values: ALLOWED_ORIGIN, AI_API_URL, AI_MODEL, and the secret AI_API_KEY. ALLOWED_ORIGIN should be the exact published MAX Pages origin, such as https://OWNER.github.io (use the exact site origin for a project site, including its path is not part of Origin). Configure the provider account and secret with help from a parent or guardian. Never share the key in chat or commit it to GitHub.\n\nAfter deploying the Worker, set API_URL near the top of the script in index.html to the Worker HTTPS endpoint, commit the change, and redeploy Pages. Then test with a simple question.\n\n## Publish the frontend\nIn the repository, open Settings → Pages. Choose Deploy from a branch, select main and /(root), then Save. Wait for the Pages deployment to finish.\n
